TECH4FUTURE-GLOBAL MANAGEMENT SYSTEM — DJANGO + FASTAPI BACKEND

UI
The V12 visual interface is preserved. styles.css and branded assets are unchanged.

BACKEND
Django: identity, password hashing, ORM, PostgreSQL, admin, roles, organizations, files, email, migrations.
FastAPI: /api/v1 authentication, workspace state, high-volume records, users/invitations, attendance, AI, Word/Excel exports, health APIs.

START WITH DOCKER
1. Copy .env.example to .env and replace secrets/passwords.
2. docker compose up --build
3. Open http://localhost:8000/
4. FastAPI docs: http://localhost:8000/api/v1/docs
5. Django admin: http://localhost:8000/django-admin/

PRODUCTION
Use HTTPS, managed PostgreSQL, object storage, backups, MFA/SSO, secrets management, a reverse proxy/load balancer, centralized logs and monitoring.
